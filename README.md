# Atharv Jangid — Portfolio

A responsive, single-page portfolio for Atharv Jangid, a Python developer and Computer Science student at JECRC University. The site introduces Atharv, highlights selected projects and skills, and links to his CV and contact information.

## Features

- Responsive layout for desktop, tablet, and mobile
- Professional navy, slate, and blue color palette
- Accessible navigation, keyboard focus states, and a skip link
- Light and dark themes with the selected theme saved in the browser
- Project, skills, education, and achievement sections
- Downloadable CV and email contact links
- No frameworks, build tools, or external runtime dependencies

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

Open the portfolio HTML file in a browser. No installation or build step is required.

For GitHub Pages, place the portfolio at the repository root and name it `index.html`. Keep the CV PDF alongside it so the download links work:

```text
.
├── index.html
├── Atharv_Jangid_PythonDev_CV.pdf
└── README.md
```

The current working portfolio file is named `Untitled-3.html`; rename it to `index.html` when adding it to the repository for the default GitHub Pages URL to load automatically.

## Deploy with GitHub Pages

1. Add `index.html` and `Atharv_Jangid_PythonDev_CV.pdf` to the root of the repository.
2. Push the files to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Once deployment finishes, open the URL shown in the Pages settings.
